## Dataset

The raw CSV files are not stored in this repository due to file size limits.

### Download Dataset
- Source: [Olist Brazilian E-Commerce Dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
- Platform: Kaggle (free account required)

### Files Required
After downloading, you will have these 9 CSV files:
- olist_orders_dataset.csv
- olist_order_items_dataset.csv
- olist_order_payments_dataset.csv
- olist_order_reviews_dataset.csv
- olist_customers_dataset.csv
- olist_products_dataset.csv
- olist_sellers_dataset.csv
- olist_geolocation_dataset.csv
- product_category_name_translation.csv

### Import Instructions
Follow the SQL commands in `/sql/analysis_queries.sql` to import all files into MySQL.
